# Base documentaire du RAG

Les fichiers de ce dossier (`.pdf`, `.md`, `.txt`) sont indexés par le RAG
d'AIDE-IoT, en plus des fiches techniques déposées dans chaque projet.
Les agents IA citent les passages récupérés sous la forme [S1], [S2]…

Ajoutez ici les documentations constructeur et références techniques
(fiches ESP32, modules LoRa, cellules 18650, régulateurs, etc.).
Chaque fichier n'est vectorisé qu'une fois (cache dans `media/rag_cache/`).

Ce fichier README n'est pas indexé.
